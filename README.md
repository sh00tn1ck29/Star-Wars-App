# Star Wars Galaxy Explorer

### [Live Demo](https://star-wars-app-pi-bay.vercel.app/)

A responsive SPA built with React and TypeScript to explore Star Wars characters, their films, and starships through an interactive graph. Data is loaded from [SWAPI](https://swapi.info/).

---

### Key Features

- **Character Directory:** Paginated list with character selection.
- **Interactive Graph:** Custom character, film, and starship cards with dragging, panning, and zoom controls.
- **Data Loading:** Parallel API requests, in-memory caching, request cancellation, and loading and error states with retry controls.
- **Feature-Based Structure:** UI features with nested components, entity gateways and types, and shared utilities.
- **Responsive UI:** Mobile-first layout, animated helmet loader, and background music controls.

---

### Tech Stack

- **Framework & Language:** [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Graph Visualization:** [React Flow](https://reactflow.dev/)
- **API Requests:** [Axios](https://axios-http.com/)
- **Styling:** [Sass (SCSS)](https://sass-lang.com/), [BEM](https://en.bem.info/methodology/)
- **Build & Quality:** [Vite](https://vite.dev/), [ESLint](https://eslint.org/)
- **Deployment:** [Vercel](https://vercel.com/)
